# TradeScope

一個給主動交易員使用的 Web 儀表板，整合：

- 美股指數（QQQ / DIA ...）
- 加密貨幣（BTC / ETH）
- 重要美國經濟事件（Core CPI、FOMC、Non-farm）
- 簡單的市場情緒說明 & 今日觀點

## Features

- 今日總覽：美股 / 加密表現 + 恐懼貪婪風格的情緒指標  
- 可點擊 BTC / ETH 卡片，展開 TradingView 可互動 K 線圖  
- 重要宏觀新聞區塊（標題 + 連結）  
- 上一次關鍵經濟數據（例如上一個 Core CPI / FOMC 決策）的摘要

## Tech stack

- React + Vite
- CSS (dark theme)
- TradingView widget for interactive charts
